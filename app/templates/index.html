What you can do

Annotate a VCF

Upload a GRCh38 VCF (plain or .gz). Every ALT allele is matched to the precomputed release and you get back the same VCF with AnnotateMissense_score, _pred and _status INFO fields.

Query the REST API

curl {{ request.host_url }}api/v1/variant/22:36305985:G:A — JSON responses, CORS enabled, no key required.

Run it locally

Download the DuckDB release from Zenodo and use the same server or the annotatemissense command line offline — no upload of patient data needed.

Scope. AnnotateMissense is a precomputed lookup: it returns scores for the GRCh38 nonsynonymous SNVs in the release (dbNSFP v5.1 CAGI7 Annotate-All-Missense set). It does not run the model on new alleles, indels or other builds. An allele that is not found has no score — absence is not evidence of benignity. Scores are for research prioritisation, not clinical classification.
