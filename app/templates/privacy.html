Privacy

This server sets no cookies, runs no analytics and stores no submitted variants or files. Uploads are parsed in memory, answered, and discarded.

The web server keeps a per-IP request counter in memory for rate limiting only. Standard access logs (time, path, status) may be written by the hosting process; they do not contain uploaded file contents.

Batch results are kept in your own browser (localStorage) so the results page can display them; clear your browser storage to remove them.

For identifiable or clinical data, do not upload: download the release and annotate offline with annotatemissense annotate-vcf, which makes no network requests.
