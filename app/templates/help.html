What is scored

AnnotateMissense is a precomputed lookup. Scores exist for the GRCh38 nonsynonymous single-nucleotide variants of the CAGI7 Annotate-All-Missense input (dbNSFP v5.1; 90,643,830 rows). The server does not run the model on new alleles; indels, MNVs and non-coding variants are reported as not_snv or not_in_release. A missing score is not evidence of benignity.

Coordinates must be GRCh38/hg38, 1-based. Lift GRCh37 data over first. Chromosomes can be written 22 or chr22.

Input formats

  • Single variant: chromosome, position, reference and alternate allele.
  • Variant list: one per line, separated by spaces, tabs or commas — 22 36305985 G A; or 22:36305985:G:A in the API.
  • VCF: v4.x, plain or gzip/bgzip; multi-allelic ALTs are split and each ALT is scored separately. Padded representations such as CG>CA are trimmed to the SNV G>A.

Interpreting the output

  • Score (0–1): AnnotateMissense XGBoost probability of pathogenicity.
  • Prediction: D (damaging) if score ≥ 0.5, otherwise T (tolerated).
  • Confidence: probability of the predicted class, max(score, 1 − score). The release stores it in a column named UQ_sd/sd; it is not a standard deviation.
  • One score per allele. The database can hold several rows for an allele when protein-level annotations (ESM1v) map to several proteins; the score is identical across them. The Transcript context panel shows which transcript each source used.
  • Legacy names: UQ_score = AnnotateMissense score, UQ_pred = prediction, UQ_BioSig_model_Final.tsv.gz = the released AnnotateMissense prediction table.

Scores support research prioritisation and variant triage. They are not clinical classifications; integrate them with ACMG/AMP evidence and expert review.
